# Desi Merge: Visual Redesign Audit (Phase 6.5)

Date: 2026-10-28. Project: Unity 6000.6.7f1, URP 2D, Android target. Starting point: commit `8ae6060`, with a clean working tree (Phases 1–6 committed). Nothing uncommitted needed preserving.

## 1. What actually exists (verified in the project, not assumed)

| Area | Finding |
|---|---|

## 2. What was reusable

- **Reused:** the architecture (generated scenes, `UITheme`, `UiFactory`), every runtime component (`GameplayHud`, `PowerUpButton`, the animations, `MergeEffects`, `ScorePopupLayer`, `ToastPresenter`), the palette direction (truck-art magenta, teal, saffron, navy), the sparkle texture and the audio.
- **Not reusable as final presentation:** the tinted circles, the per-item text labels, the repeating background pattern, the block walls, the Arial-style font and the text-only power-up buttons.

## 3. Changes made

1. **Item artwork:** 10 original illustrated sprites drawn by an Editor rasterizer (`ArtCanvas`, `ItemArtGenerator`), each sized to its collider circle, in full colour. A new `MergeItemDefinition.tintSprite` flag (off for the new art) keeps the tint as the accent colour for effects only. Text labels were removed from the item prefab.
2. **UI art set:** shaded panel, lipped button, pill, disc, glow, ring, truck-art ornament, border strip, background gradient, wall tile, dashed danger line, 17 icons and an app icon (`GameArtGenerator`).
3. **Design system:** `UITheme` gained card and muted colours, the new sprites, a display font (Lilita One, OFL) plus a body font, a button-lip size and motion timings. `ContentSetup.ApplyDesignSystem` sets the tokens.
4. **Playfield:** `MergeBoard` now builds colliders (`Walls`, no renderers) and decorative art (`Art`, no colliders) separately: patterned walls and floor, ornament caps, a soft field panel and a dashed coral danger line. Wall geometry is unchanged.
5. **HUD:** one navy top bar with a saffron rim and border strip; large score; crown + best; a "next" well showing the real next sprite; a round pause button; square Hammer/Shuffle buttons with icons, labels and count badges, plus selected and unavailable states. All top elements are now in one `TopHud` container scaled by `ResponsiveScaler`, which also fixes the tablet toast overlap.
6. **Screens:** cream cards with navy header ribbons. The pause card has **Resume / Restart (with confirmation) / Main Menu**. The game-over card has the score, NEW BEST badge, best line, Continue (only when the real ad coordinator offers it), Play Again and Main Menu. The main menu was redesigned (illustrated title, decorative items, icon tiles, best-score badge hidden when there is no best), as were the Settings, Collection (item art, lock icon on undiscovered silhouettes) and Achievements panels.
7. **Game feel:** merge pop with squash-and-stretch (visual child only), a merge ring burst (second ParticleSystem, one particle per merge), and the existing sparkles, popups, button press and panel transitions.
8. **Launcher icon:** the default Player Settings icon is set to the generated mango icon. No other Player Settings changed.

## 4. Risks and how they are handled

| Risk | Handling |
|---|---|
| Rebuilding generated scenes overwrites manual edits | Documented in the menu dialog; nobody had hand-edited the scenes. Data assets (items, configs, saves, audio) are kept. |
| Art changing collision feel | Physics is untouched: same collider radius, masses, materials and walls. A test checks every sprite stays inside its collider circle. Art sits slightly inside the circle (chai, shake and leaf have small gaps), which is a visual-only difference. |
| Merge-balance drift | A test pins every level's ID, order, radius and score to the shipped values. |
| Decorations interfering with physics | Board art lives on a separate `Art` child with no colliders or bodies. A scene test checks that only walls and items have colliders. |
| Font licensing | Lilita One is under the SIL Open Font License 1.1 (commercial use and embedding allowed). The license text ships next to the font, and a test checks it is there. |
| Texture memory | Item sprites are 512² with mipmaps and platform compression (ASTC on Android). UI sprites are ≤256² (background 32×256). Totals are in the asset manifest. |
| Legacy `Text` instead of TextMeshPro | Kept to avoid a large risky rewrite of every UI script and test. The display font gives the polish; TMP can come later. |
| Item rotation | Items still rotate with physics (rule unchanged). The art uses uniform scale, so it never distorts, but the highlight rotates with the item. |
