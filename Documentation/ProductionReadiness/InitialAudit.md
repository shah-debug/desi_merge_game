## Project baseline

| Area | Actual state |
|---|---|
| Unity | 6000.6.7f1, URP 2D, Input System 1.20.1, Test Framework 1.8.0 |
| Packages | Only Unity packages (2D, URP, uGUI, Input System, Timeline, Visual Scripting, IDE, collab-proxy). **No third-party SDKs**: no ads, analytics, crash reporting or networking libraries. |
| Scenes (build order) | 0 `Bootstrap` (composition root, splash) → 1 `MainMenu` → 2 `Gameplay`. All three are generated by Editor code. |
| Architecture | One `GameBootstrapper` (DontDestroyOnLoad, duplicate guard) builds `GameServices` once and hands them to each scene's `ISceneEntryPoint`. No static service locator; no `FindObjectOfType` at runtime. |
| Persistence | `JsonRepository` + `FileSaveStore`: write to `.tmp`, then atomic `File.Replace` keeping `.bak`; load main → backup → defaults, with corrupt files kept as `*_corrupt`. Nine save files. |
| Network | No project code uses the network (no `UnityWebRequest`, `System.Net` or `HttpClient`). Unity Cloud services, analytics and crash reporting are **disabled** in `UnityConnectSettings`. |
| Ads | Interface only. A release build uses `UnavailableRewardedAdService` (Continue is hidden); development builds use `SimulatedRewardedAdService`. No ad SDK. |
| Analytics | Debug log only in development builds; `NullAnalyticsService` in release. |
| Android (generated Gradle) | `applicationId com.DefaultCompany.DesiMerge`, `versionName 1.0`, `versionCode 1`, `minSdk 26`, `targetSdk 36`, `compileSdk 36`, IL2CPP, ARM64, portrait only, engine code stripping on, **`signingConfig signingConfigs.debug`**, `installLocation preferExternal` |
| Permissions | `android.permission.INTERNET` only, added by Unity's defaults. The game never uses it. |
| Splash | Unity splash off; branded splash in `Bootstrap.unity` |
| Secrets | No API keys, passwords, tokens or keystores in `Assets/` or `ProjectSettings/` (searched) |
| Tests at baseline | EditMode 203, PlayMode 110: both passed in the final Phase 6.6 runs |
| Devices | `adb devices`, using the adb that ships with scrcpy, lists **no device or emulator**. No Android emulator is installed. |

## First risk list (examined in this phase)

1. Data loss when storage throws on read (an unreadable file treated as "no save").
2. Daily systems after wrong device dates (far future, backwards).
3. Tampered or impossible values in the new Phase 6.6 save files.
4. Duplicate or lost merges under rapid drops and clusters; double scoring.
5. Input mashing: pause, restart, game over, power-ups and menu panels.
6. Release configuration: package ID, signing, permissions.
7. Lifecycle on a real Android device (cannot be run here; see `AndroidDeviceTestReport.md`).
